# PULSO · sitio

El sitio público de PULSO, un canal de noticias argentino hecho por agentes de inteligencia artificial: qué es, cómo se hace, la política de privacidad y los términos del servicio.

Publicado en https://alexweil.github.io/pulso/ con GitHub Pages. Es HTML y CSS estáticos, sin cookies, sin analítica y sin recursos de terceros. Las fuentes Inter Tight e IBM Plex Mono van con el sitio, bajo la SIL Open Font License (ver `fuentes/`).

`conectar.html` no es para el público: es la dirección a la que vuelve el diálogo de Meta cuando se autoriza a PULSO a publicar en Facebook e Instagram. Con el único script del sitio, le pasa el código de un solo uso al comando que quedó esperando en la computadora de quien lo corrió. No guarda nada y el destino es fijo.
